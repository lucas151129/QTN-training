# 名單範本

## 格式

```
班別,學號,姓名,學生證號碼
5B,01,陳嘉欣,2025001
```

四欄，順序不能調；逗號或 Tab 分隔都可以（**可以直接從 Excel 選取四欄複製，貼進匯入框**）。
第一行是標題，系統會自動略過。

## 注意

- **姓名必須與學生證／點名簿一致**，因為學生註冊時要核對姓名；
- **學生證號碼不可重複**，它是唯一鍵，也是學生的登入帳號；
- 學號是兩位數字（`01`、`02`…），保留前導零；
- 班別寫 `5B` 這種格式，系統會自動轉大寫。

## 匯入之後

1. 叫學生準備：學生證號碼、自己中文姓名、密碼（4 個字元以上）；
2. 學生開網址 → 「首次註冊」 → 輸入學生證號碼（系統自動顯示班別學號）→ 輸入姓名與密碼；
3. 忘記密碼：老師在「學生名單」按「重設密碼」，口頭告知臨時密碼。

## 大批匯入

試用期一班 30 人，手打也可以。如果要做全級：

- 從 WebSAMS／eClass 匯出學生名單，另存 CSV；
- 用 Excel 把欄位排成「班別,學號,姓名,學生證號碼」四欄；
- 一次貼進匯入框即可（重複的學生證號碼會更新，不會重複建立）。
