# 備份與匯出

## 這裡會有甚麼

| 東西 | 怎麼來 |
|---|---|
| `backup-YYYY-MM-DD-HH-MM/` | 執行 `備份.ps1` 或 `node scripts/backup.mjs` 產生 |
| `backup-*.zip` | `備份.ps1` 順便壓縮 |
| 成績 CSV | 老師在「作業 → 匯出成績 CSV」下載，建議存在這裡 |

## 備份的內容

```
backup-2026-11-26-17-00/
├─ app.db          ← VACUUM INTO 產生的完整資料庫（不必關伺服器）
├─ uploads/        ← 學生相片，按提交編號分資料夾
└─ manifest.json   ← 時間、檔案數、學生數
```

## 還原

1. 關掉伺服器（Ctrl+C）；
2. 把 `app.db` 與 `uploads/` 覆蓋回 `程式/data/`；
3. 重新啟動。

## 建議做法

- **每天放學後**跑一次 `備份.ps1`（30 秒）；
- 每星期把 zip 複製到一個雲端或另一台機（3-2-1 原則：至少兩份、其中一份不在同一台機）；
- **學期尾**：整份 `程式/data/` 壓縮封存，命名 `2026-27_上學期_科學科.zip`，然後清空資料庫再開始新學期。

## 不要做的事

- 不要直接複製「使用中」的 `app.db`（可能複製到寫了一半的狀態）——用 `備份.ps1` 或先關伺服器；
- 不要把備份 zip 放在同一個資料夾就算了，硬碟壞了會一起消失。
