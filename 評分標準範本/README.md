# 評分標準範本（rubric）

## 怎麼用

1. 老師登入 → 「+ 新增作業」；
2. 在「從範本載入…」下拉選一個範本；
3. 改一改題目與評分點 → 建立作業。

新增範本：把一個 `.json` 檔放進這個資料夾，重新整理網頁就會出現在下拉選單。

## 檔案格式

```json
{
  "name": "顯示在下拉選單的名稱",
  "subject": "小學科學",
  "class_name": "5B",
  "description": "給學生看的說明（可省略）",
  "questions": [
    {
      "no": "1",
      "tag": "知識點（用於班級弱點分析）",
      "type": "text | text_photo | photo",
      "prompt": "題目文字",
      "points": [
        { "id": "1-1", "desc": "評分點描述", "score": 2 }
      ]
    }
  ]
}
```

`score` 加起來就是該題滿分，不用另外寫總分。

## 現有範本

| 檔案 | 科目 | 特點 |
|---|---|---|
| `P5科學_物質的變化.json` | 小學科學 | 概念＋實驗設計＋反思，四題示範 |
| `P5科學_力與運動.json` | 小學科學 | 設計與製作類，含公平測試與數據處理 |
| `P4數學_分數應用題.json` | 小學數學 | 示範同一套系統用於數學（列式／計算／答句） |
| `P6英文_Descriptive_Writing.json` | 小學英文 | 示範寫作 rubric（內容／語言／組織） |

> 三個科目都可以用同一套系統——差別只在評分點怎麼寫。
> 寫法見 `方案文件/05_怎麼寫評分點.md`。
